# Líquidos Penetrantes

Header navigation (top gradient bar): Filosofía · Servicios (→ radiografía) · Sistema de Gestión · Factura Electrónica. Logo links to home.

Service side menu: Radiografía · Partículas Magnéticas · Otras Técnicas · Ultrasonido · Líquidos Penetrantes · Equipos

El método o técnica de inspección mediante LIQUIDOS PENETRANTES es una de las técnicas más utilizadas para la inspección superficial de partes y/o piezas de materiales no porosos aplicada principalmente al control de calidad de soldaduras que deben cumplir y/o alcanzar requerimientos según estándares, especificaciones y códigos tales como API, ASME, AWS, AWWA entre otros durante fases de construcción y/o mantenimiento de:

Oleoductos, Gasoductos, Acueductos, Tanques de almacenamiento, estaciones y facilidades petroleras, refinerías y plantas químicas, recipientes de presión, puentes y estructuras en general
