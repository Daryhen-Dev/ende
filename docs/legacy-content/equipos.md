# Equipos

Header navigation (top gradient bar): Filosofía · Servicios (→ radiografía) · Sistema de Gestión · Factura Electrónica. Logo links to home.

Service side menu: Radiografía · Partículas Magnéticas · Otras Técnicas · Ultrasonido · Líquidos Penetrantes · Equipos

- Instrumentos para medición de niveles de radiación.
- Película radiográfica, químicos, elementos auxiliares para procesamiento y toma radiográfica
- Cámara de gammagrafía y elementos auxiliares de seguridad radiológica.
- Equipos de Ultrasonido, set de bloques de calibración, palpadores y cables.
- Yoques de magnetización y elementos auxiliares (medidores de luz , fuentes de iluminación , etc.
- Líquidos penetrantes en aerosol y a granel - medidores de luz
- Elementos auxiliares para verificación de calidad y evaluación radiográfica
